# Пояснення кожного рядка HTML і CSS

Це окремий навчальний файл. Початковий код сайту не змінено. Номери відповідають поточній версії файлів; після редагування коду вони можуть змінитися. Наведено всі рядки, зокрема порожні.

## Як читати CSS

- `.назва` вибирає клас, `#назва` — id, назва тега — всі такі елементи; пробіл вибирає нащадків. Кома об’єднує селектори.
- `rem` залежить від розміру шрифту кореневого елемента, `vw` — 1% ширини вікна, `%` залежить від відповідного розміру контейнера, `fr` розподіляє доступний простір Grid. CSS px — одиниці CSS, не обов’язково фізичні пікселі екрана.
- `var(--назва)` підставляє CSS-змінну. `clamp(мінімум, бажане, максимум)` обмежує гнучке значення. `calc()` обчислює вираз.
- Правила медіазапиту діють лише за його умовою. За однакової специфічності пізніше правило перевизначає попереднє.
