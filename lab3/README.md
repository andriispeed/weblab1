# Адаптивна персональна сторінка

Для перегляду відкрийте `index.html` у браузері. Збірка та встановлення залежностей не потрібні.

## Що змінено

- Замість фіксованої ширини 1440 px контейнер має `width: 100%` та обмеження `max-width: 80rem`. На вузькому екрані він займає доступну ширину, на широкому — залишається по центру.
- Прибрано фіксовані висоти шапки й меню. Висота визначається вмістом і відступами.
- Структуру організовано через `header`, `nav`, `main`, `section`, `article`, `aside` і `footer`. `article` представляє окреме досягнення, `aside` — додаткову контактну інформацію. Допоміжні `div` залишено лише для оформлення та прокручування.
- Невдалу сітку з трьох колонок замінено двома рівними колонками на Desktop. Раніше дисципліни займали лише третину ширини, через переноси блок ставав високим і залишав порожню ділянку під біографією. Тепер обидва блоки ширші та розтягуються до однакової висоти рядка через `align-items: stretch`.
- Досягнення й контакти розміщено на всю ширину сітки. Контакти більше не стискають картки досягнень.
- Зменшено максимальні розміри заголовків, тексту та відступів. Функція `clamp(мінімум, гнучке значення, максимум)` плавно змінює їх залежно від ширини вікна в заданих межах.
- Меню побудовано через Flexbox із `flex-wrap: wrap`: посилання переносяться на новий рядок, якщо місця недостатньо.
- Таблиця зберігає табличну структуру, підпис `caption` і заголовки зі `scope`. Обгортка з `overflow-x: auto` дозволяє прокручувати лише розклад. Мінімальна ширина таблиці в `rem` потрібна для читабельності шести колонок; час заняття не розривається на рядки.
- Для клавіатури передбачено видимий фокус і можливість фокусувати область таблиці через `tabindex="0"`. За налаштуванням `prefers-reduced-motion` анімації вимикаються.

## Як працюють контрольні ширини

| Категорія | Ширина вікна | Компонування |
| --- | --- | --- |
| Mobile | до 767 px | Усі секції та картки досягнень в одну колонку. Меню під шапкою, посилання переносяться. Таблиця прокручується горизонтально за потреби. |
| Tablet | 768–1023 px | Основні секції залишаються на всю ширину для читабельності. Картки досягнень — у дві колонки, контакти — у гнучкий горизонтальний рядок. |
| Desktop | від 1024 px | Біографія та дисципліни — у дві рівні колонки. Шапка та меню стоять поруч у пропорції 3:2. Розклад, досягнення й контакти займають всю ширину. |

CSS написано за принципом mobile first: базові правила описують телефон, `@media (min-width: 768px)` додає зміни для планшета, а `@media (min-width: 1024px)` — для комп’ютера. Назва пристрою не визначає режим: наприклад, iPad із шириною вікна 1032 CSS px отримує Desktop-компонування відповідно до вимог завдання.

`minmax(0, 1fr)` створює рівні гнучкі колонки Grid. Нульова нижня межа та `min-width: 0` у секцій дозволяють їм стискатися, навіть якщо всередині є широка таблиця. `grid-column: 1 / -1` розтягує блок через усі колонки. Для сітки не використовуються `float` або абсолютне позиціонування.

## Файли

- `index.html` — семантична структура та вміст.
- `css/base.css` — кольори, шрифти, гнучкі розміри.
- `css/header.css`, `css/menu.css` — шапка й навігація.
- `css/content.css` — сітка, секції, таблиця, картки та контрольні ширини.
- `css/footer.css` — підвал із перенесенням елементів.
- `css/style.css` — підключення стилів, контейнер і спільні правила.

## Перевірка

Компонування перевірено в Microsoft Edge на ширинах 320, 375, 767, 768, 1023, 1024, 1032, 1440 і 1920 CSS px. Горизонтального переповнення всієї сторінки немає. Для ручної перевірки відкрийте інструменти розробника, увімкніть режим пристроїв і змінюйте ширину вікна; на телефоні перевірте горизонтальне прокручування розкладу.
