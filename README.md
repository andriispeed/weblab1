# IT.SCHOOL — командний вебпроєкт

Сайт ІТ-школи у стилі **функціоналізм**, основний колір **#7A5C00**. Проєкт міститься в [Ind/](Ind/). Інші папки — окремі лабораторні роботи.

**Команда:** Шкіндер Андрій, Хомяк Дар’я, Арсеній Липський, Карпець Олександр.

**Angular + NestJS + PostgreSQL.** Чотири публічні сторінки, каталог із фільтрами, серверна форма заявки та захищена адмінпанель. Сайт працює на VPS через Nginx і HTTPS.

**Ролі:** Андрій — бекенд, сервер, адмінпанель та API; Олександр — Angular-сторінки й каталог; Дар’я — адаптивна верстка та CSS-градієнти; Арсеній — форма запису й клієнтська валідація.

**Change Request №15:** компроміс — триколірний градієнт у великих заголовках, основний текст однотонний. Перегляд Figma-макетів `design-preview` вилучено з публічного сайту; матеріали збережено локально.
