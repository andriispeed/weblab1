# IT.SCHOOL — командний вебпроєкт

Сайт ІТ-школи у стилі **функціоналізм**, основний колір **#7A5C00**. Проєкт міститься в [Ind/](Ind/). Інші папки — окремі лабораторні роботи.

**Команда:** Шкіндер Андрій, Карпець Олександр, Хомяк Даря.

- [Панель команди](https://telegrambot.vps.webdock.cloud/it-school/admin).
- [Дизайн-рішення CR15](https://telegrambot.vps.webdock.cloud/it-school/design).

- [Figma: плагіни й імпорт](Ind/design/README.md).
- [Текст командного захисту](Ind/docs/DEFENSE.md).

**Angular + NestJS + PostgreSQL.** Чотири публічні сторінки, каталог із фільтрами, серверна форма заявки та захищена адмінпанель. Сайт працює на VPS через Nginx і HTTPS.

**Change Request №15:** компроміс — триколірний градієнт у великих заголовках, основний текст однотонний. Посилання на власний Figma-файл і фактичний розподіл ролей команда має додати в [README проєкту](Ind/README.md).
