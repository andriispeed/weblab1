# IT.SCHOOL — генератор макетів Figma

Готовий локальний Figma-плагін для навчального завдання: сайт ІТ-школи, функціоналізм, основний колір **#7A5C00**. Код уже зібраний у `code.js`: встановлювати Node.js або виконувати команди для першого запуску не потрібно.

## Запуск — приблизно 1 хвилина

1. Відкрий **настільний застосунок Figma** та порожній **Figma Design** файл із правом редагування.
2. Натисни правою кнопкою на полотні → **Plugins → Development → Import plugin from manifest…**. Залежно від версії інтерфейсу меню може починатися з **Select plugins**.
3. Вибери файл `C:\5sem\web\Ind\figma-plugin\manifest.json`.
4. Відкрий **Plugins → Development → IT School · Midterm Generator** і запусти його.
5. Дочекайся повідомлення «Готово». Генератор перемістить перегляд до головної Desktop-сторінки.
6. Для демонстрації відкрий **Present** та вибери сценарій **IT.SCHOOL / Desktop**, **IT.SCHOOL / Tablet** або **IT.SCHOOL / Mobile**.

Офіційні інструкції Figma щодо [імпорту локального плагіна](https://help.figma.com/hc/en-us/articles/38457121114263-Create-a-Figma-Design-plugin-with-the-Figma-MCP-server-and-agentic-tools).

`id` у manifest — локальний ідентифікатор розробки. Публікація плагіна в Community для цього завдання не потрібна.

## Що буде створено

- **12 повних макетів**: головна, каталог, курс Python, контакти/запис у Desktop 1440 px, Tablet 768 px та Mobile 390 px.
- **UI-kit із 25 компонентами/варіантами**: кнопки трьох типів у чотирьох станах, поля у чотирьох станах, фільтри, бейдж, логотип, кнопки меню та три картки курсів.
- Справжні **Component / ComponentSet / Instance**, текстові стилі, прив’язані змінні кольорів і відступів та Auto Layout.
- Приховані колонкові сітки: 12 / 8 / 4 колонки. Їх можна ввімкнути в налаштуваннях фрейму.
- **61 екран прототипу**: основні сторінки, фільтри, деталі трьох курсів, вибраний напрям у заявці, порожні/заповнені/помилкові форми, підтвердження та мобільне меню.
- Три окремі сценарії з фіксованими областями перегляду та вертикальним прокручуванням: 1440×900, 768×1024 та 390×844.

Повні макети розташовані в секціях **Desktop / Tablet / Mobile**, а екрани для Present — нижче, в секціях **Prototype**. Так повні сторінки видно на полотні, а в демонстрації вони коректно прокручуються.

Плагін працює на поточній сторінці Figma та додає результат праворуч від наявних об’єктів. Наявні макети не видаляються. Повторний запуск створює ще один комплект; кольорові та числові змінні й текстові стилі з відповідними іменами використовуються повторно. Для першого запуску зручно взяти порожній файл.

## Як перевірити прототип

1. Головна → **Обрати свій курс** → Каталог.
2. Натисни **Розробка**: залишаться Frontend і Python; **Тестування** покаже QA.
3. Відкрий картку Python → **Записатися на курс**. У формі вже обраний Python.
4. Спробуй надіслати порожню форму: з’явиться стан помилки.
5. Натисни поле імені або email: відкриється підготовлений стан із демонстраційними даними.
6. Натисни **Надіслати заявку**: відкриється підтвердження.
7. На Mobile перевір відкриття меню та повернення кнопкою ×.

Форма є клікабельним UX-прототипом: довільне введення тексту та реальне надсилання даних не реалізовані. Ціни, контакти й назва школи демонстраційні. Figma-макети потребують перегляду й затвердження викладачем.

## Перегляд без Figma

Відкрий `preview.html` у браузері подвійним кліком. У верхній панелі є перемикач пристрою, сторінки та UI-kit. Переходи працюють. Файл автономний: шрифт Inter уже вбудований, сервер та інтернет не потрібні.

Це браузерний перегляд спільної дизайн-специфікації. Самі редаговані шари Figma створюються після запуску плагіна. `preview.html` не замінює семантичну HTML-верстку чотирьох сторінок для здачі завдання.

## Редагування коду

- `src/design.ts` — тексти, палітра, компоненти, сторінки й сценарії.
- `src/plugin.ts` — створення нативних шарів та переходів Figma.
- `src/preview.ts` — браузерний перегляд тієї самої специфікації.
- `manifest.json` та `code.js` — готовий плагін для імпорту.
- `assets/InterVariable.woff2` — Inter; ліцензія в `assets/Inter-LICENSE.txt`.

Після змін виконай у цій папці:

```powershell
npm.cmd ci
npm.cmd run check
npm.cmd run build
npm.cmd run verify
```

Перевірка браузера використовує встановлений Microsoft Edge. Перевіряються всі маршрути, посилання на компоненти, горизонтальні межі макетів, обрізання тексту фіксованої висоти та сценарії користувача для всіх трьох пристроїв. Знімки 12 основних сторінок, UI-kit і звіт зберігаються в `qa/`.

Код перевірено за офіційними типами Figma Plugin API, браузерний перегляд перевірено автоматично та візуально. **Безпосередній запуск у Figma в цьому сеансі не виконувався**: інструменти підключеного у VS Code Figma MCP недоступні цьому сеансу.

## Для здачі Midterm

Після імпорту переглянь фрейми та Present, додай учасників команди й посилання на файл Figma до README основного проєкту та погодь концепцію з викладачем. Наступний етап у коді сайту — довести чотири HTML-сторінки до структури макетів і завантажити репозиторій на GitHub.

Коли викладач видасть випадкову додаткову вимогу, зафіксуй її окремо та обери імплементацію або аргументоване відхилення. Генератор не вигадує вимогу наперед.
