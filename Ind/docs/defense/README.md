# Матеріали для кожного учасника

Основний захист розрахований на **9 хвилин 15 секунд + 45 секунд запасу**. [Повний спільний сценарій із репліками](../DEFENSE.md).

Перешли кожному його окремий файл: він містить роль, карту файлів, пояснення функцій/станів/HTML або CSS, готовий текст виступу, дії на екрані та відповіді на запитання.

| Учасник | Файл | Час |
|---|---|---|
| Карпець Олександр | [OLEKSANDR.md](OLEKSANDR.md) | 0:00–2:00 |
| Хомяк Дар’я | [DARIA.md](DARIA.md) | 2:00–4:00 |
| Арсеній Липський | [ARSENII.md](ARSENII.md) | 4:00–6:00 |
| Шкіндер Андрій | [ANDRII.md](ANDRII.md) | 6:00–9:15 |

Порядок виступу: **Олександр → Дар’я → Арсеній → Андрій**. Номер заявки з частини Арсенія використовується в частині Андрія.

Текст виступу в кожній пам’ятці та у спільному сценарії однаковий. Решта матеріалу — для підготовки, її не потрібно зачитувати вголос. Спочатку прочитати свою пам’ятку, відкрити зазначені файли й пройти сценарій; потім провести спільну репетицію.

Розподіл файлів описує відповідальність у команді. Для спільних файлів окремо зазначено межі: адмінпанель і API залишаються за Андрієм, форма й клієнтська валідація — за Арсенієм, навігація — за Олександром, адаптивні стилі — за Дар’єю.
