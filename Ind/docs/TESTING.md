# Перевірки IT.SCHOOL

**18.11.2026:** production-збірки, повний HTTPS E2E, ізольований PostgreSQL integration test, перевірки Figma та GitHub Actions пройдені. У E2E — 40 публічних комбінацій сторінки/ширини й 4 ширини адмінпанелі, JavaScript-помилок не виявлено. Контрольний `pg_dump` відновлено в окрему БД; кількості записів і контрольна сума курсів збіглися. Власні тестові заявки видалено, ціну курсу відновлено; заявки від користувачів збережені.

[Перевірки GitHub Actions](https://github.com/andriispeed/weblab1/actions/workflows/it-school.yml).

## Автоматичні перевірки

- Production-збірки Angular і NestJS із TypeScript.
- `npm audit --omit=dev`: відомі вразливості production-залежностей.
- `scripts/verify-live.mjs`: реальний HTTPS-сайт, Microsoft Edge через Playwright.
- `backend/test/api.mjs`: окрема тестова PostgreSQL для CI, ім’я БД обов’язково закінчується `_test`.
- Figma: перевірка типів, 61 екран, 25 компонентів, 635 цілей переходів; 12 макетів × 3 режими CR15.

## Наскрізний сценарій

40 комбінацій публічних сторінок і ширин: головна, каталог, три курси, контакти, CR15, вхід; 320 / 390 / 768 / 1024 / 1440 px. Окремо панель перевіряється на 320 / 390 / 768 / 1440 px. Перевіряються завантаження стилів, градієнт заголовків та відсутність горизонтального скролу.

Каталог: фільтр, пошук, порожній результат та скидання. Меню: відкриття, Escape. Форма: вибраний курс, помилки, згода, серверна відповідь. Адміністратор: нова заявка з мобільного браузера, зміна статусу, збереження після перезавантаження, зміна курсу через UI та API. Також перевіряються Swagger і публічний дизайн-перегляд під CSP.

API: відмова без входу, cookie HttpOnly/Secure/SameSite, перевірка полів і Origin, ідемпотентність заявки, CSRF, зміна статусу, фільтри, відхилення застарілої версії курсу, видалення тестових записів.

Тести реального сайту створюють лише власні позначені записи, відновлюють змінену ціну й прибирають тестові заявки. Звіти та знімки зберігаються в локальній папці `qa/`, яка не публікується в Git.

## Межі

Результати на конкретних ширинах не є повним аудитом усіх браузерів або сертифікацією WCAG. Контраст палітри розрахований, але дослідження читання реальними користувачами не проводилося. Польових даних Core Web Vitals немає. Нативний Figma-плагін потребує запуску та перевірки в командному файлі.
