# Архітектура IT.SCHOOL

Реалізовано 18.11.2026. Публічна адреса: https://telegrambot.vps.webdock.cloud/it-school/

## Відповідальність частин

- **design/** — локальні матеріали макетів, які не публікуються на сайті. `tokens.json` — джерело кольорів Angular. Публічний `design-preview` вилучено 19.11.2026.
- **frontend/** — Angular 20.3, standalone components, lazy routes, Reactive Forms, HttpClient, signals, SCSS. Основні сторінки й панель завантажуються окремими маршрутами.
- **backend/** — NestJS, TypeScript, валідація DTO, серверні сесії, параметризований SQL через `pg`.
- **infra/** — Docker Compose, Nginx include, пакетне розгортання з перевірками та резервні копії.

Для невеликої схеми використано прямі SQL-запити через `pg`. Початкова пропозиція TypeORM не стала частиною фінального стека. Схема змінюється через версійовані міграції у транзакції, а не через автоматичне перезаписування таблиць.

## Дані

| Таблиця | Що зберігає |
|---|---|
| courses | Три курси, ціна, опис, програма, версія запису |
| applications | Ім’я, email, напрям, повідомлення, статус, ключ повторного запиту |
| admin_users | Ім’я адміністратора і scrypt-хеш пароля |
| sessions | Хеш випадкового токена, CSRF, термін дії 8 годин |
| audit_log | Хто змінив статус/курс або видалив заявку; без тексту заявки |
| migrations | Застосовані версії схеми |

## HTTP

Публічні методи: `GET /courses`, `GET /courses/:id`, `POST /applications`, `GET /health`.

Авторизація: `POST /auth/login`, `GET /auth/me`, `POST /auth/logout`.

Захищені методи: `GET /admin/applications`, `PATCH /admin/applications/:id`, `DELETE /admin/applications/:id`, `PATCH /admin/courses/:id`, `GET /admin/audit`.

Зовнішній префікс усіх методів — **/it-school/api/**. [Повна документація](https://telegrambot.vps.webdock.cloud/it-school/api/docs/).

## Відвідувач і команда

1. Angular отримує курси з API.
2. Клієнтська та серверна перевірки обробляють заявку.
3. Сервер зберігає запис, повертає номер; повторний requestId не створює дубліката.
4. Адміністратор входить через HttpOnly cookie.
5. Панель отримує заявки, змінює статус або курс; сервер перевіряє сесію, Origin і CSRF.
6. Оновлення курсу потребує поточної версії, тому застаріла форма не перезаписує чужу зміну.

## Сервер

Наявний Nginx віддає Angular із `/var/www/it-school` і проксіює API до **127.0.0.1:3100**. Основний застосунок за кореневою адресою і на порту 3001 збережено. База доступна тільки в приватній Docker-мережі. Для API є окрема мережа із прив’язкою порту до localhost.

Під час перевірки API використовував приблизно 40 MiB, PostgreSQL — 41 MiB; це спостереження на малому навантаженні, не результат навантажувального тесту. Обидва контейнери обмежені 256 MiB. На VPS із 1 CPU і 1,6 GiB RAM TypeScript/Angular не компілюються: їх збирають до завантаження.

Задіяно наявний сертифікат для того самого домену. Для цього розгортання не потрібні новий порт у браузері або зміни DNS.

## Обмеження

Немає платежів, автоматичних листів, реального навчального кабінету студента чи автоматичного зарахування. Це навчальна система із серверним прийманням заявок. Нативний Figma-файл потрібно оновити через локальний плагін. Щоденні backups розміщені на VPS; контрольна копія завантажується локально, постійного автоматичного off-site сховища немає.
