# Figma: Change Request 15

Плагін працює з уже створеними макетами. Старий Midterm Generator повторно запускати не потрібно.

## Створити порівняння

1. Відкрий свій Figma Design файл у настільній Figma.
2. Plugins → Development → Import plugin from manifest… → вибери **цей** `manifest.json` із папки `Ind/design/figma-change-request`.
3. Виділи одну готову сторінку, наприклад **Desktop / Головна**.
4. Запусти **IT School · CR15 Gradient Text → Порівняння: оригінал / повна вимога / компроміс**.
5. Плагін додасть окрему секцію з трьома редагованими копіями: початковий макет, градієнт усього основного тексту, градієнт великих заголовків.

Для підсумкового варіанта вибери всі 12 оригінальних фреймів або секції **Desktop / Tablet / Mobile** та запусти **Копії з градієнтними заголовками**. UI-kit не виділяй. Вибрані фрейми зберігаються; створюються нові копії.

Наявні переходи між вибраними сторінками перенаправляються на відповідні копії того самого варіанта. Переходи до невибраних сторінок залишаються такими, як у джерелі. Нові переходи для Tablet / Mobile автоматично не вигадуються. Перед демонстрацією перевір Desktop у Present.

## Межі автоматизації

- Великі заголовки визначаються за розміром від 24 px і накресленням Medium / Semi Bold / Bold. Це підходить до раніше згенерованих макетів; змінені вручну назви або розміри перевір окремо.
- Кнопки, меню, поля форми та футер виключені з основного інформаційного тексту.
- Для світлого фону застосовується `#7A5C00 → #4F356E → #245F57`; для темного — `#FFE3A3 → #E3D5FF → #B8E8DD`.
- Текст на зображенні, невизначеному/напівпрозорому фоні або з недостатнім розрахованим контрастом пропускається. Кількість пропусків показана під макетами: перевір їх вручну.
- Типи перевірені за Figma Plugin API. Запуск усередині твого Figma-файлу в цьому сеансі не виконувався.

Офіційна інструкція [імпорту локального плагіна](https://help.figma.com/hc/en-us/articles/38457121114263-Create-a-Figma-Design-plugin-with-the-Figma-MCP-server-and-agentic-tools).
